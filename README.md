# Be a President

Ein kleines Browserspiel für unsere Präsentation: Du bist Bundespräsident und musst entscheiden, ob du Gesetze ausfertigst (unterschreibst) oder ablehnst.

## So spielt man

1. Das Kabinett bringt eine Akte herein.
2. Klick auf die blaue Mappe: Worum geht es?
3. Klick auf das Grundgesetz: Prüfhinweise.
4. Grüner Stempel = ausfertigen, roter Stempel = ablehnen.
5. Danach siehst du, ob deine Entscheidung richtig war, und warum.

Jede Amtszeit hat 6 Akten, zufällig aus 10 Fällen gezogen. Wer nebeneinander sitzt, bekommt also unterschiedliche Fälle in anderer Reihenfolge.

## Dateien

- `index.html`: das Spiel
- `faelle.js`: alle 10 Fälle mit Hinweisen und Lösung (hier kann man Texte ändern)
- `assets/`: Hintergrundbild und Einlauf-Video

- `bethebundespraesident.html`: die ältere, einfachere Version
